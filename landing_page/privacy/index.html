Kebijakan Privasi (Privacy Policy)

Terakhir Diperbarui: 13 Oktober 2026 • Berlaku Efektif: Versi 1.0

Ringkasan Komitmen Kami: Cardly (disediakan melalui domain cardly.suntree.my.id) adalah aplikasi pengatur catatan kartu dan dokumen privat. Kami tidak pernah menjual data pribadi Anda, tidak memproses transaksi pembayaran, dan melarang keras penyimpanan kredensial perbankan sensitif (nomor kartu 16-digit lengkap, CVV, atau PIN perbankan).

1. Pendahuluan

Kebijakan Privasi ini menjelaskan bagaimana Cardly ("kami", "aplikasi", atau "layanan") mengumpulkan, menggunakan, menyimpan, dan melindungi informasi Anda saat Anda menggunakan aplikasi mobile Cardly serta situs web kami di cardly.suntree.my.id.

Dengan mengunduh, mengakses, atau menggunakan Cardly, Anda menyetujui praktik data yang dijelaskan dalam Kebijakan Privasi ini.

2. Data yang Kami Kumpulkan

A. Informasi yang Diberikan Pengguna Secara Langsung

  • Informasi Akun: Nama lengkap dan alamat email yang Anda berikan saat mendaftar akun Cardly atau masuk melalui Google OAuth.
  • Metadata Kartu & Dokumen: Nama alias kartu, penerbit kartu, 4 digit terakhir nomor kartu, masa berlaku, kategori dokumen, dan tanggal pengingat yang Anda masukkan.
  • Berkas Dokumen Lokal: Foto atau pindaian dokumen (KTP, SIM, paspor, kartu asuransi) yang Anda pilih untuk disimpan di dalam brankas aplikasi.

B. Data yang Secara Tegas TIDAK PERNAH Kami Kumpulkan

Untuk melindungi keamanan finansial Anda sekelas enterprise:

  • Kami TIDAK PERNAH meminta atau menyimpan nomor kartu kredit/debit lengkap (16 digit).
  • Kami TIDAK PERNAH meminta atau menyimpan kode keamanan CVV / CVC.
  • Kami TIDAK PERNAH meminta PIN ATM, PIN perbankan, atau kode OTP transaksi bank.

3. Penggunaan Data Pengguna Google (Google OAuth)

Aplikasi Cardly menyediakan opsi masuk cepat menggunakan Google Sign-In. Terkait data yang kami terima dari antarmuka Google API:

  • Data yang Diakses: Alamat email utama dan nama profil akun Google Anda.
  • Tujuan Penggunaan: Data tersebut semata-mata digunakan untuk mengidentifikasi akun Anda, mengamankan sesi masuk, dan mengaitkan brankas cloud Anda.
  • Kepatuhan Google API Services: Penggunaan dan transfer informasi yang diterima dari Google API oleh Cardly ke aplikasi lain akan mematuhi Google API Services User Data Policy, termasuk persyaratan Penggunaan Terbatas (Limited Use requirements).
  • Tidak Ada Pihak Ketiga: Kami tidak pernah membagikan, meminjamkan, atau menjual data profil Google Anda ke pengiklan atau pialang data pihak ketiga mana pun.

4. Penyimpanan dan Keamanan Data

A. Penyimpanan Lokal (On-Device First)

Data utama Anda diproses dan disimpan secara lokal di dalam database terstruktur SQLite di memori ponsel pintar Anda. Berkas fisik dokumen Anda dilindungi oleh sandbox sistem operasi perangkat keras Anda.

B. Sinkronisasi Cloud Aman Terenkripsi

Jika Anda mengaktifkan fitur sinkronisasi cloud:

  • Data dienkripsi saat transit menggunakan protokol TLS/HTTPS berstandar modern.
  • Data disimpan dalam basis data cloud privat yang dilindungi oleh Row Level Security (RLS). Kebijakan ini secara matematis menjamin bahwa hanya token identitas unik akun Anda yang berhak membaca atau memodifikasi data Anda.

C. Keamanan Sesi Biometrik & PIN

Cardly mengintegrasikan perlindungan biometrik hardware (Fingerprint / Face ID) dan PIN 6 digit mandiri. Kunci enkripsi sesi disimpan di Secure Storage tingkat hardware (iOS Keychain dan Android Keystore).

5. Hak Pengguna dan Penghapusan Data (Data Deletion)

Kami meyakini kedaulatan data mutlak berada di tangan Anda:

  • Pembersihan Lokal Seketika (Emergency Wipe): Anda dapat menghapus seluruh data kartu, dokumen, berkas, dan preferensi lokal kapan pun melalui tombol "Hapus Data Brankas" di menu Keamanan & Brankas aplikasi.
  • Permintaan Penghapusan Akun & Data Cloud: Anda berhak meminta penghapusan akun secara permanen beserta seluruh data cadangan di server cloud kami. Permintaan dapat diajukan secara langsung dengan mengirimkan email ke muchlisinmaruf@gmail.com dengan subjek "Permintaan Penghapusan Akun Cardly". Kami akan memproses penghapusan total dalam waktu 7 hari kerja.

6. Layanan Pihak Ketiga

Aplikasi kami menggunakan layanan infrastruktur pihak ketiga tepercaya berikut untuk mendukung fungsinya:

  • Google Identity Services: Untuk memfasilitasi autentikasi Google OAuth secara aman.
  • Infrastruktur Cloud Privat Terenkripsi: Untuk penyediaan otentikasi akun, penyimpanan cloud terenkripsi, dan basis data dengan Row Level Security.
  • Cloudflare: Untuk penyediaan DNS, perlindungan DDoS, dan sertifikat enkripsi SSL/TLS pada domain web cardly.suntree.my.id.

7. Privasi Anak-Anak

Layanan kami tidak ditujukan untuk anak-anak di bawah usia 13 tahun. Kami tidak secara sengaja mengumpulkan informasi identitas pribadi dari anak-anak.

8. Perubahan Kebijakan Privasi Ini

Kami dapat memperbarui Kebijakan Privasi kami dari waktu ke waktu. Setiap perubahan akan diumumkan dengan memperbarui tanggal "Terakhir Diperbarui" di bagian atas dokumen ini.
