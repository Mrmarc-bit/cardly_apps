Panduan Pemasangan

3 Langkah Mudah Memasang Cardly

Karena Cardly didistribusikan secara mandiri untuk privasi maksimal, Android memerlukan izin satu kali untuk memasang file APK.

01

Unduh Berkas APK

Klik tombol "Unduh Berkas APK" di atas sesuai varian chipset ponsel Anda. Tunggu hingga file selesai diunduh di bar notifikasi ponsel Anda.

02

Izinkan Sumber Ini

Saat membuka file, jika Android menampilkan konfirmasi "Demi keamanan, ponsel tidak diizinkan...", ketuk Setelan (Settings) $\rightarrow$ aktifkan "Izinkan dari sumber ini".

03

Pasang & Update Otomatis

Ketuk "Instal". Setelah terbuka, Cardly akan secara otomatis memeriksa pembaruan di latar belakang setiap ada rilis fitur baru.

Ponsel membuka aplikasi WPS Office alih-alih menginstal APK? Pada beberapa ponsel (terutama Infinix XOS atau Xiaomi), sistem dapat salah mengasosiasikan berkas APK ke aplikasi pembaca dokumen WPS. Solusi cepat: Buka aplikasi Pengelola File (File Manager) bawaan ponsel Anda, buka folder Download atau tab APK, lalu ketuk berkas Cardly APK untuk memasang langsung via Penginstal Paket Android.
